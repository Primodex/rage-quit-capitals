# America's Rage-Quit Capitals — Which U.S. Cities Have the Worst Internet for Gaming?

Interactive ranking for CompareInternet.com (Infinity Sales Group; Fractl DJC campaign).
Scores the 50 largest U.S. cities on seven measures that decide whether online gaming feels
smooth: ping, download speed, upload speed, performance consistency, fiber availability,
provider choice, and local Google search interest in gaming lag. Includes the full sortable
ranking, worst-on-each-measure tables, a map, a city-vs-typical-city comparison, and an FAQ.

- Single self-contained file: `index.html` (no external dependencies).
- **To serve it:** Settings → Pages → deploy from `main`, root (`/`). The page loads at the Pages URL.
- Rank 1 = worst of 50 cities. New York is scored on partial data (ZIP file covers Manhattan only).

Data: M-Lab speed tests (2023), CompareInternet.com ZIP code provider data, FCC broadband data,
Google Trends. Source: CompareInternet.com study.
